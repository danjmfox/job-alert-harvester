# Refusal codes

Doc type: Reference

This list was generated by reading the refusal enums in `src/` as of commit e077171 (`git rev-parse --short HEAD`). Sources: `src/core/sheets-refusals.mjs` (`SheetsRefusal`, `DriveRefusal`, `ImportRefusal`, `BuildRefusal`, `AuthTargetRefusal`), `src/core/oauth.mjs` (`AuthRefusal`, `TokenRefusal`, `CredentialRefusal`), `src/core/retry-policy.mjs` (`RetryRefusal`), `src/core/endpoints.mjs` (`EndpointRefusal`), `src/core/gmail-message.mjs` (`MessageRefusal`), `src/core/coverage.mjs` (`CoverageRefusal`), `src/adapters/gmail-api-source.mjs` (`SourceRefusal`), `src/adapters/raw-spill-source.mjs` (`SpillRefusal`), `src/adapters/ledger-store.mjs` (`LedgerRefusal`), `src/adapters/message-cache.mjs` (`CacheRefusal`), `src/adapters/xlsx-target-sheet.mjs` (`TargetRefusal`), `src/cli/fetch-loop.mjs` (`FetchRefusal`), and `src/core/slim.mjs` (`QuarantineReason`). Regenerate it after any change to those enums.

Meanings are read from the code that raises each refusal. "Usual cause" entries are inferred from that code unless a decision record or a live run names the cause.

A refusal prints on stderr as `<code>` or `<code>: <detail>` and the command exits with status 1. Messages never contain a credential value. The commands are described in [cli.md](cli.md).

Some errors have no code and are not listed here: missing required options, `harvest build: ...` messages for an empty cache, an existing `--out`, or `--merge` and `--out` naming different files, `harvest: --in ...` messages, and raw operating-system errors. Those are in [cli.md](cli.md) and the how-to guides.

## Credentials: `gmail.credential-*` and `sheets.credential-*`

The two namespaces behave identically. `gmail.*` applies to `client.json` and `token.json`; `sheets.*` applies to `client.json` and `sheets-token.json`.

| Code | Meaning | Usual cause | What to do |
|---|---|---|---|
| `gmail.credential-missing`, `sheets.credential-missing` | The credential directory, `client.json`, or the token file does not exist. | Setup not done, or `auth` not run for this profile. | Follow [Set up Google Cloud credentials](../how-to/set-up-google-cloud.md). |
| `gmail.credential-invalid`, `sheets.credential-invalid` | A credential path is a symlink or the wrong kind of entry, or the JSON is unreadable or has the wrong shape. | A Web-type client file (no `installed` object), a hand-edited token, or a symlink. | Download a Desktop client again, or run `auth` again. |
| `gmail.credential-permissions`, `sheets.credential-permissions` | The directory mode is not exactly 0700, or a file has a group or other permission bit. | Default umask, or files copied from elsewhere. | `chmod 700` the directory and `chmod 600` each file. |

## Tokens: `gmail.*` and `sheets.*`

| Code | Meaning | Usual cause | What to do |
|---|---|---|---|
| `gmail.reauth-required` | The token endpoint answered `invalid_grant` for the refresh token. | Token expired or revoked: seven-day expiry of an External app in Testing, a password change, revoked access, an administrator action. | Run `node src/cli/harvest.mjs auth`. |
| `sheets.reauth-required` | As above, for the Sheets token. The message adds `run harvest auth --target sheets`. | As above. | Run `node src/cli/harvest.mjs auth --target sheets`. |
| `gmail.token-endpoint-error`, `sheets.token-endpoint-error` | A token refresh failed for any reason other than `invalid_grant`: malformed answer, network failure, or 429 or 5xx after 3 attempts. | Network or Google outage. | Run the command again later. |
| `gmail.scope-mismatch`, `sheets.scope-mismatch` | The granted scope is not exactly `gmail.readonly` (Gmail) or `drive.file` (Sheets). | Wrong scope granted, or a token file from another profile. | Run the matching `auth` command again. |

## Consent: `auth.*`

| Code | Meaning | Usual cause | What to do |
|---|---|---|---|
| `auth.state-mismatch` | The redirect carried a different `state` from the one sent. | An older consent URL was used. | Run `auth` again and use only the newest URL. |
| `auth.consent-denied` | The redirect reported an error. | Consent declined or blocked. | Run `auth` again and approve. |
| `auth.no-code` | The redirect carried no authorisation code. | Interrupted or malformed redirect. | Run `auth` again. |
| `auth.no-refresh-token` | Google returned no refresh token. | The code path does not establish the cause. | Remove the app's access in your Google account settings, then run `auth` again. |
| `auth.exchange-failed` | The authorisation code could not be exchanged: rejected, malformed answer, or network failure. | `client.json` from a different project than the enabled APIs, or a network fault. | Check the client, then run `auth` again. |
| `auth.consent-timeout` | No redirect arrived within 5 minutes. | The URL was not opened in time, or on another machine. | Run `auth` again and open the URL at once, on the same machine. |
| `auth.unknown-target` | `--target` is not `gmail` or `sheets`, or has no value. | Typo. | Use `--target gmail` or `--target sheets`. |

| `sheets.quota-exhausted` | Rate-limited after 3 attempts. | About 60 write requests per minute per user. | Wait a minute, then run again. |
| `sheets.server-error` | A 5xx answer persisted for 3 attempts on a read. | Google outage. | Run again later. |
| `sheets.request-rejected` | Any other 4xx answer. | A request Google refused. | Report it. |
| `sheets.response-malformed` | A Sheets or Drive answer lacked the expected shape. | API change. | Report it. |

| `sheets.key-column-missing` | `Jobs` has no `Dedup Key` column, or a populated `Companies` (`Company`) or `Sources` (`Source` and `Search Term`) tab lacks its key column. | Header renamed or deleted. | Restore the header. |

| `sheets.apply-outcome-unknown` | A 5xx or lost connection persisted while writing; the Sheet may or may not have changed. | Google fault or network loss. | Run the build again; it will not append twice. |

## Drive: `drive.*`

Raised by `import` while creating or deleting the Sheet. The write is sent once and never replayed.

| Code | Meaning | Usual cause | What to do |
|---|---|---|---|
| `drive.quota-exhausted` | A 429, or a 403 with a quota reason. | Too many requests. | Wait, then run `import` again. |
| `drive.server-error` | A 5xx or lost connection. | Google fault. A Sheet may have been created. | Check Drive for a stray file named after your workbook, then run `import` again. |
| `drive.unauthorized` | A 401 after one token refresh, or a 403 without a quota reason. | Drive API not enabled, scope missing. | Enable the API, then run `auth --target sheets`. |
| `drive.request-rejected` | Any other 4xx answer. | A request Google refused. | Report it. |
| `drive.storage-full` | A 403 with reason `storageQuotaExceeded`. | Drive has no free space. | Free space, then run `import` again. |
| `drive.response-malformed` | The create answer was not a native Sheet with an id. | API change. | Report it. |
| `drive.not-created-here` | A delete was requested for an id this process did not create. | A defect in the harvester. | Report it. |

## Spill (agent path): `spill.*`

Raised by `ingest`. Nothing is ingested when one is raised.

| Code | Meaning | Usual cause | What to do |
|---|---|---|---|
| `spill.directory-absent` | The `--raw` directory does not exist. | Wrong path. | Correct `--raw`. |
| `spill.count-mismatch` | The count of matching files differs from `--expect`. The detail reads `expected <n>, found <m>`. | Partial batch, or files from another window. | Stage only this window's files and pass the exact count. |
| `spill.not-json` | A file is not JSON. The detail names it. | Truncated file. | Fetch that message again. |
| `spill.not-a-message` | A file lacks a string `id`, `date` or `sender`. | Wrong file. | Remove it from the directory. |
| `spill.missing-plaintext-body` | A file has no non-empty `plaintextBody`. | Wrong format requested from the connector. | Fetch it with full content. |
| `spill.outside-window` | A message's UTC date is outside `--window`. | A file from another window. | Remove it from the directory. |

## Quarantine reasons: `slim.*`

These are not refusals and do not stop a command. They print as `quarantined <id> (<reason>)`, the message is not cached, and its day is still committed.

| Reason | Meaning | Usual cause | What to do |
|---|---|---|---|
| `slim.body-too-short` | The plain-text body is under 1024 characters. | A truncated payload. | Inspect the message in Gmail; none is retried automatically. |
| `slim.no-advert-link` | The body has no `/jobs/view/` link. | A non-digest message, or a changed email layout. | As above. |
